# Sushi icon pack (third-party)

16x16 sushi icons. Drop-in candidates for the species sprites.

To use one, copy it to `assets/sprites/fish/` and rename it to the
`SpeciesDef.id` it represents. Mapping suggestions:

| Pack file | Species id |
|---|---|
| Sushi_Tuna_maguro.png | lean_tuna |
| Sushi_Salmon.png | salmon |
| Sushi_fatty_tuna_toro.png | (new species) |
| Sushi_mackerel_saba.png | mackerel |
| Sushi_flounder_fin_engawa.png | sea_bream |
| Sushi_egg_omelet_tamago.png | (new species) |
| Sushi_octopus_tako.png | (new species) |
| Sushi_shrimp_ebi.png | (new species) |
| Sushi_surf_clam_hokkigai.png | (new species) |

They are sushi (prepared), not whole fish; the tank/freezer may prefer
whole-fish art later. Keep the source here either way.
