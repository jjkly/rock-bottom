# Title letters

Seven unique letters shared by "ROCK BOTTOM": `R, O, C, K, B, T, M`.
The menu assembles the word from them, stretches R and B (the capitals) to
122px and the rest to 94px, and bobs each letter.

Source files live in `assets/sprites/backgrounds/Title/` (R/O/C/K/B/M are
64×64; the supplied T was an editor screenshot, so `T.png` here is a
repainted 64×64 letter in the same palette).

To change a letter, overwrite the matching file in this folder. Missing files
fall back to the plain "Rock Bottom" text.
